# Словарь данных (Data Dictionary) для сеансов связи LEO

**Происхождение:** это **синтетический** датасет, который я сгенерировала сама с помощью скрипта `leo_data_pipeline.generator` (использовался `random.Random(202611)`). Это не реальная телеметрия, скачанная с космических аппаратов.

| Колонка | Тип / единицы | Описание |
|---|---|---|
| `event_id` | строка | Уникальный ключ события связи. Я специально добавила дубликаты, чтобы проверить работу очистки. |
| `timestamp_utc` | ISO 8601 | Время события в формате UTC (мировое время). |
| `satellite_id` | строка | ID синтетического спутника (`KA-01` ... `KA-16`). |
| `orbital_plane` | целое число | Номер орбитальной плоскости (от 1 до 4). |
| `station_name` | строка | Название одной из шести виртуальных наземных станций (названы в честь городов). |
| `station_lat_deg` | градусы | Приблизительная широта станции для группировки. |
| `station_lon_deg` | градусы | Приблизительная долгота станции. |
| `frequency_ghz` | ГГц | Частота сигнала на линии "вниз" (от спутника к Земле). |
| `elevation_deg` | градусы | Упрощенный угол возвышения спутника над горизонтом. |
| `slant_range_km` | км | Наклонная дальность (расстояние от станции до спутника). |
| `pass_duration_s` | секунды | Длительность сеанса связи. |
| `rain_rate_mm_h` | мм/ч | Интенсивность дождя. Здесь специально есть пропуски и битые значения. |
| `cloud_cover_pct` | проценты | Облачность. |
| `tx_power_w` | Ватты | Мощность передатчика. |
| `tx_antenna_gain_dbi` | dBi | Коэффициент усиления передающей антенны (dBi - изотропный децибел). |
| `rx_antenna_gain_dbi` | dBi | Коэффициент усиления приемной антенны. |
| `polarization` | категория | Поляризация сигнала: правая круговая (RHCP) или левая круговая (LHCP). |
| `mission_priority` | целое число | Приоритет миссии (от 1 до 3). |
| `system_temperature_k` | Кельвины | Шумовая температура системы. |
| `path_loss_db` | дБ | Потери сигнала в свободном пространстве (FSPL - Free Space Path Loss). |
| `snr_db` | дБ | Отношение сигнал/шум (SNR - Signal-to-Noise Ratio) после учета погоды и шумов. |
| `capacity_mbps` | Мбит/с | Пропускная способность канала (рассчитана по формуле Шеннона для полосы 25 МГц). |
| `transferred_gb` | ГБ (десятичные) | Объем переданных данных за сеанс (1 ГБ = 1e9 байт). |
| `link_status` | категория | Статус сеанса: `success` (если SNR >= 2 дБ), иначе `failed`. |
| `operator_note` | строка | Свободный текстовый комментарий (синтетический). |

**Что добавляет ETL при обработке:**
- `rain_rate_mm_h_imputed`, `cloud_cover_pct_imputed` - булевы флаги, показывающие, было ли значение заполнено вместо пропуска.
- `contact_date` - дата события в UTC.
- `usable_pass` - бинарный признак (1 - успех, 0 - провал).
- `rain_class` - класс дождя (`dry` - сухо, `moderate` - умеренно, `heavy` - сильно).

**Правила очистки:** исходные колонки обязательны. После удаления дубликатов `event_id` должен быть уникальным. Время переводится в UTC. Угол возвышения должен быть от 0 до 90 градусов, дождь и объем данных не могут быть отрицательными, проценты - от 0 до 100, приоритет - от 1 до 3. Строки с физическим бредом отбрасываются, а их количество фиксируется в отчете. Пропуски в погоде заполняются медианой по конкретной станции, а если данных нет - глобальной медианой.
