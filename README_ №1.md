# Домашнее задание №1

## 1. Датасет 

**Urban Environment Monitoring Dataset** — авторский синтетический датасет для анализа городской среды и качества воздуха.

- Размер: **2518 строк × 24 столбца**
- Формат: **CSV**
- Тип данных: структурированные табличные данные
- Размер файла: существенно меньше 5 ГБ
- В датасете намеренно присутствуют пропуски, дубликаты, неидеальные категории и выбросы для последующей практики очистки и анализа данных.

**Ссылка на датасет:** [urban_environment_monitoring.csv](https://disk.yandex.ru/d/iQpw6DbwRX1ygA)

> Сам CSV-файл не хранится в GitHub-репозитории в соответствии с условием задания. Репозиторий содержит только описание данных и воспроизводимый скрипт генерации.

## 2. Предметная область

Датасет имитирует почасовые наблюдения сети городских экологических станций. Каждая запись описывает состояние окружающей среды в определённый момент времени: концентрации загрязнителей воздуха, метеорологические параметры, транспортную нагрузку, шум, характеристики территории и техническое состояние датчика.

Данные можно использовать для:

- анализа качества воздуха по районам и времени;
- поиска факторов, связанных с ростом PM2.5 / PM10 / NO2;
- анализа влияния трафика, ветра, осадков и зелёных зон;
- поиска аномалий и неисправностей сенсоров;
- построения моделей прогнозирования загрязнения воздуха или категории AQI;
- практики preprocessing: пропуски, дубликаты, выбросы, категориальные признаки.

## 3. Как получен датасет

Датасет создан самостоятельно с помощью Python-скрипта `scripts/generate_dataset.py` с фиксированным `random seed` для воспроизводимости. Значения генерируются не полностью независимо: например, уровень транспортной нагрузки влияет на концентрации NO2 и частиц, скорость ветра уменьшает накопление загрязнителей, а тип городской территории влияет на фоновые уровни и шум.

После генерации специально добавлены типичные проблемы реальных данных:

- пропущенные измерения;
- точные дубликаты строк;
- разные варианты написания категорий (`Central`, ` Central`, `Central ` и т.п.);
- несколько физически подозрительных сенсорных значений;
- текстовые заметки оператора с большим количеством пропусков.

## 4. Словарь признаков

| Признак | Тип | Описание |
|---|---|---|
| `record_id` | object | Идентификатор записи |
| `timestamp` | datetime/object | Дата и время измерения |
| `station_id` | category | Идентификатор станции мониторинга |
| `district` | category | Район города |
| `land_use` | category | Тип территории: residential, commercial, industrial, mixed, park |
| `sensor_model` | category | Модель сенсора |
| `latitude` | float | Широта станции |
| `longitude` | float | Долгота станции |
| `pm25_ug_m3` | float | Концентрация PM2.5, мкг/м³ |
| `pm10_ug_m3` | float | Концентрация PM10, мкг/м³ |
| `no2_ug_m3` | float | Концентрация NO2, мкг/м³ |
| `o3_ug_m3` | float | Концентрация O3, мкг/м³ |
| `temperature_c` | float | Температура воздуха, °C |
| `humidity_pct` | float | Относительная влажность, % |
| `wind_speed_m_s` | float | Скорость ветра, м/с |
| `wind_direction_deg` | float | Направление ветра, градусы |
| `precipitation_mm` | float | Осадки, мм |
| `traffic_index` | float | Индекс транспортной нагрузки, 0–100 |
| `distance_to_road_m` | float | Расстояние станции до крупной дороги, м |
| `green_space_pct` | float | Доля зелёных территорий поблизости, % |
| `noise_db` | float | Уровень шума, дБ |
| `aqi_category` | category | Категория качества воздуха |
| `maintenance_status` | category | Технический статус сенсора |
| `operator_note` | text | Текстовая заметка оператора |

## 5. Примеры проблем качества данных

В наборе есть несколько типов «грязи», которые можно обнаружить и обработать в следующих работах:

- **18 полных дубликатов**;
- пропуски в `pm25_ug_m3`, `no2_ug_m3`, `o3_ug_m3`, `humidity_pct`, `wind_speed_m_s` и `operator_note`;
- неунифицированные значения в `district` и `maintenance_status`;
- выбросы, например PM2.5 до **401.03 мкг/м³**, влажность до **117%**, шум до **130.8 дБ**.
